## 文档编制原则

本文档体系刻意保留了所有阈值、超时、防护措施的**出处** —— 每一个数字（90 分钟、0.5/1.5 比例、900 秒看门狗、600 MB 内存上限）都能追溯到一次真实的实测或事故。这与代码注释的规范一致：

> 阈值、超时、闸门比例这些数字如果没有出处，下一个维护者只能靠猜。猜错的代价是重新经历一遍同样的事故。
